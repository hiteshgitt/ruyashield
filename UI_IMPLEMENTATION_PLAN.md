Motion guarantees (M5):
- All motion runs only under `prefers-reduced-motion: no-preference`. With reduced motion the page is static and fully visible.
- Without JavaScript nothing is hidden: content is only hidden when the inline boot script runs, and a 3-second failsafe reveals it even if GSAP fails to load.
- Pointer effects need a fine pointer that can hover and a width of at least 1024px. Touch devices get no tilt or magnetic effects.
- No infinite loops. The one repeating effect stops after 3 cycles (WCAG 2.2.2).
- GSAP never touches markup inside Suspense or client-rendered boundaries before hydration, so there are no hydration mismatches.
- QA: 13 widths still pass. Motion tests at 390 and 1440 confirm no element stays hidden after a full scroll and there are no console errors.

Content rules applied:
- Every mock is on example.com and labelled "Illustrative example — not live data".
- Only implemented capabilities are described. There are no pricing numbers, customers, testimonials, certifications or named repo providers.
- Results are described as "not a certification or a compliance attestation".
